# Core evidence and its limits

tlaw does not use “the test suite is green” as a synonym for correctness. Its
core value boundaries have layered evidence, and each layer supports a
different conclusion.

## Maintained layers

1. Ordinary unit and property tests exercise public examples, invalid inputs,
   exact failure reports, and generated values. They establish observed
   behavior over deterministic examples and Hypothesis-generated cases.
2. `verification/crosshair_contracts.py` states small contracts without using
   tlaw as its own assertion oracle. `scripts/crosshair` accepts only
   `Confirmed over all paths` for every retained contract; `Not confirmed`, a
   timeout, or a changed contract count fails the gate.
3. `self_laws/` states the domain, comparison, exclusion, and typed-replay
   boundaries through tlaw's public interface. These laws run in the fast push
   gate, independently of the ordinary pytest suite.
4. `scripts/core-evidence` mutates the core implementation files while leaving
   their self-laws unchanged. It succeeds only when every generated runnable
   mutation is killed or has an explicit reviewed equivalent declaration. The
   dedicated CI workflow runs this slower evidence on relevant changes, on
   demand, and weekly. The script reports the generated site count from the
   current source instead of relying on a number in documentation that can go
   stale as the implementation or mutation operators change.

CrossHair is a development dependency only. tlaw itself still has only
Hypothesis and pytest as runtime dependencies. The contracts use CrossHair's
assert analysis directly; no runtime contract decorator is needed.

## What the result means

When both scripts pass, it is justified to say:

- every checked test and law held in that run;
- CrossHair confirmed each retained symbolic assertion over all paths within
  its modeled functions and preconditions; and
- the self-laws rejected every mutation generated by tlaw for the declared
  core boundaries.

It is not justified to say that all Python behavior is formally proved. The
symbolic contracts are deliberately small, mutation strength is relative to
the implemented mutation operators, Hypothesis explores rather than
exhaustively enumerates general inputs, and unmodeled third-party or operating
system behavior remains outside these claims. A green result is strong,
reproducible evidence with an explicit boundary—not metaphysical certainty.

## Why these tools

CrossHair adds value because it gives an independent SMT-backed analysis of
pure contracts and distinguishes confirmation from an unfinished search.
`icontract` is not added: its runtime pre/postcondition vocabulary would
duplicate tlaw's own contract surface, while CrossHair can analyze assertions
directly. Pynguin is not added either: generated coverage cases without a
trusted behavioral oracle do not strengthen these core semantic claims as
directly as handwritten properties plus mutation grading.

Run the complete maintained evidence with:

```console
./scripts/gate
./scripts/core-evidence
```
