`tlaw mutate` now confirms a kill only when the replay reproduces the same evidence, not just the same verdict: a timeout and a law failure can no longer confirm each other, an observed kill must name the same laws twice, and a timeout kill is re-timed against a baseline measured immediately before its replay so a contended machine cannot manufacture a kill. Reports gain a `kill_kind` per mutation and a separate count of kills by calibrated timeout, which name no law.
